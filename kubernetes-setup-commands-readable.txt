================================================================================
                    KUBERNETES CLUSTER SETUP GUIDE
================================================================================

🎯 WHAT THIS GUIDE DOES:
   • Sets up 1 Master Node (Kubernetes Control Plane)
   • Sets up 2 Worker Nodes (Application Workloads)
   • Creates a fully functional 3-node cluster

📋 BEFORE YOU START:
   • You need 3 Ubuntu machines running
   • All machines must be able to communicate with each other
   • You need sudo access on all machines
   • Update the IP address in SECTION 5 before running!

🌐 IP ADDRESSES TO CONFIGURE:
   MASTER_NODE_IP  = 192.168.1.100    ← Change this to your master IP
   WORKER1_NODE_IP = 192.168.1.101    ← Change this to your worker1 IP  
   WORKER2_NODE_IP = 192.168.1.102    ← Change this to your worker2 IP

================================================================================
                    STEP-BY-STEP INSTRUCTIONS
================================================================================

📌 STEP 1: RUN ON ALL 3 MACHINES (Prerequisites)
================================================================================

# Update system packages
sudo apt update && sudo apt upgrade -y

# Install required packages
sudo apt install -y apt-transport-https ca-certificates curl gnupg lsb-release

📌 STEP 2: RUN ON ALL 3 MACHINES (Install Docker)
================================================================================

# Add Docker repository
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Install Docker
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io

# Configure Docker for Kubernetes
sudo tee /etc/docker/daemon.json > /dev/null <<EOF
{
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m"
  },
  "storage-driver": "overlay2"
}
EOF

# Start Docker
sudo systemctl daemon-reload
sudo systemctl restart docker
sudo systemctl enable docker

📌 STEP 3: RUN ON ALL 3 MACHINES (Install Kubernetes)
================================================================================

# Add Kubernetes GPG key
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.29/deb/Release.key | sudo gpg --dearmor -o /usr/share/keyrings/kubernetes-apt-keyring.gpg

# Add Kubernetes repository (updated for modern Ubuntu versions)
echo "deb [signed-by=/usr/share/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.29/deb/ /" | sudo tee /etc/apt/sources.list.d/kubernetes.list

# Install Kubernetes
sudo apt update
sudo apt install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl

📌 STEP 4: RUN ON ALL 3 MACHINES (System Configuration)
================================================================================

# Disable swap
sudo swapoff -a
sudo sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab

# Load kernel modules
sudo tee /etc/modules-load.d/containerd.conf > /dev/null <<EOF
overlay
br_netfilter
EOF

sudo modprobe overlay
sudo modprobe br_netfilter

# Configure networking
sudo tee /etc/sysctl.d/99-kubernetes-cri.conf > /dev/null <<EOF
net.bridge.bridge-nf-call-iptables  = 1
net.ipv4.ip_forward                 = 1
net.bridge.bridge-nf-call-ip6tables = 1
EOF

sudo sysctl --system
sudo systemctl enable kubelet

================================================================================
                    🚨 IMPORTANT: STOP HERE ON WORKER NODES! 🚨
                    Only continue to STEP 5 on the MASTER NODE
================================================================================

📌 STEP 5: RUN ONLY ON MASTER NODE (Initialize Cluster)
================================================================================

# ⚠️  CHANGE THE IP ADDRESS BELOW TO YOUR MASTER NODE IP!  ⚠️
sudo kubeadm init --pod-network-cidr=10.244.0.0/16 --apiserver-advertise-address=192.168.1.100

# Setup kubectl
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# Install network plugin
kubectl apply -f https://raw.githubusercontent.com/flannel-io/flannel/master/Documentation/kube-flannel.yml

# ⚠️  SAVE THIS OUTPUT - You need it for worker nodes!  ⚠️
kubeadm token create --print-join-command

================================================================================
                    🚨 IMPORTANT: SAVE THE JOIN COMMAND ABOVE! 🚨
                    Copy it exactly - you'll need it for the next step
================================================================================

📌 STEP 6: RUN ON WORKER NODES (Join Cluster)
================================================================================

# Use the join command from the master node
# Example: sudo kubeadm join 192.168.1.100:6443 --token abc123.def456 --discovery-token-ca-cert-hash sha256:1234567890abcdef...

sudo kubeadm join <MASTER_IP>:6443 --token <TOKEN> --discovery-token-ca-cert-hash <HASH>

📌 STEP 7: VERIFY CLUSTER (Run on Master Node)
================================================================================

# Check nodes
kubectl get nodes

# Check all pods
kubectl get pods --all-namespaces

# Check cluster info
kubectl cluster-info

================================================================================
                    🎉 CONGRATULATIONS! 🎉
                    Your Kubernetes cluster is now running!
================================================================================

📋 QUICK REFERENCE COMMANDS:
================================================================================

# Check node status
kubectl get nodes

# Check pod status
kubectl get pods -n <namespace>

# Check service status  
kubectl get services -n <namespace>

# View logs
kubectl logs <pod-name> -n <namespace>

# Execute in pod
kubectl exec -it <pod-name> -n <namespace> -- /bin/bash

================================================================================
                    🚨 TROUBLESHOOTING
================================================================================

# If you need to reset a node:
sudo kubeadm reset
sudo rm -rf /etc/cni/net.d
sudo rm -rf $HOME/.kube/config

# If token expires (run on master):
kubeadm token create --print-join-command

# Check services:
sudo systemctl status kubelet
sudo systemctl status docker

# View logs:
sudo journalctl -u kubelet -f
sudo journalctl -u docker -f

================================================================================
                    📝 IMPORTANT NOTES
================================================================================

✅ WHAT TO DO:
   • Run steps 1-4 on ALL 3 machines
   • Run step 5 ONLY on master node
   • Run step 6 on both worker nodes
   • Save the join command from master

❌ WHAT NOT TO DO:
   • Don't run step 5 on worker nodes
   • Don't forget to change the IP address
   • Don't lose the join command
   • Don't skip any steps

🔧 REQUIREMENTS:
   • Master: 2GB RAM, 2 CPU cores minimum
   • Workers: 1GB RAM, 1 CPU core minimum each
   • All nodes must communicate on port 6443
   • No firewall blocking Kubernetes ports
